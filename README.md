Bright Coffee Shop – Data Analytics Case Study

1. Project Description

Project Overview

The Bright Coffee Shop case study is a data analytics project focused on analysing coffee shop sales data to identify business trends, customer purchasing patterns and overall sales performance.

The purpose of this project is to transform raw transaction data into meaningful insights that can help the business understand its performance and make informed, data-driven decisions.

Through data cleaning, processing, analysis and visualisation, the project aims to identify opportunities for improving sales performance, product management and business operations.

Project Objectives

The main objectives of this project are to:

* Analyse overall coffee shop sales and revenue.
* Identify the best-performing products and product categories.
* Understand sales trends across different days and months.
* Identify peak sales periods throughout the day.
* Compare weekday and weekend sales performance.
* Analyse performance across different store locations.
* Develop meaningful insights and recommendations.

Dataset Description

The project uses a coffee shop transaction dataset containing information about sales, products, transactions and store locations.

The dataset includes the following fields:

* Transaction ID
* Transaction Date
* Transaction Time
* Transaction Quantity
* Product ID
* Product Category
* Product Type
* Product Detail
* Store ID
* Store Location
* Unit Price

Business Questions

The analysis aims to answer the following questions:

1. What is the total revenue generated by Bright Coffee Shop?
2. Which products and product categories generate the highest sales?
3. Which days generate the most revenue?
4. What are the busiest times of the day?
5. How does weekday performance compare to weekend performance?
6. Which store locations generate the highest revenue?
7. What recommendations can improve business performance?

The analysis aims to provide insights that can help Bright Coffee Shop:
